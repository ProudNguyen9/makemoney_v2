_variables.scss — dán vào rồi chạynpm run build

Preview đổi màu bằng cách ghi đè CSS trong iframe — chính xác 100% mọi component. Màu nền tối áp cho: topbar info, header bảng giá, footer, banner CTA, section tối, nút nổi, menu mobile. Chữ trên nền tối tự chọn combo trắng/đen theo độ sáng (WCAG); chữ trên nút primary luôn trắng. Khi ưng màu: Copy biến SCSS → dán vào assets/scss/_variables.scss → npm run build.

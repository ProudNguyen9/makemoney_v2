# MASTER PROMPT — THIẾT KẾ VÀ TẠO TRỌN BỘ FRONTEND TEMPLATE WEBSITE THU MUA PHẾ LIỆU

Bạn hãy đóng vai:

- Senior UI/UX Designer
- Senior Frontend Developer
- Senior Bootstrap Developer
- Senior Web Designer
- Senior SEO Frontend Specialist
- Conversion Rate Optimization Specialist
- Design System Architect

Nhiệm vụ của bạn là **thiết kế và tạo hoàn chỉnh một bộ Frontend Template** cho website doanh nghiệp chuyên:

Một bộ template tương đối đầy đủ nên có:

* **HTML5** chuẩn semantic.
* **Bootstrap 5.x** để responsive.
* CSS riêng, không nhét quá nhiều style trực tiếp vào HTML.
* JavaScript riêng, hạn chế inline script.
* Bootstrap Icons hoặc Font Awesome.
* Responsive Desktop / Tablet / Mobile.
* Không phụ thuộc vào framework frontend như React/Vue nếu dự án ASP.NET MVC không cần.
* Code dễ tách thành `Layout`, `Partial View`, `View`

# THU MUA PHẾ LIỆU

Đây không chỉ là thiết kế Homepage.

Tôi cần một **bộ template hoàn chỉnh có thể giao cho Backend Developer để tích hợp thành website thật**.
